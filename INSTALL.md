# Installation

1. Download `ChuyHandSymbols-Regular.ttf`.
2. Open the font file and select **Install Font** (macOS) or **Install** (Windows).
3. Select **Chuy Hand Symbols** in your application.
4. If v1 is already installed, replace it with v2.

Version 2 includes uppercase symbols, a distinct handwritten lowercase alphabet, and Vietnamese vowels with all five tone marks. Numbers and punctuation are not yet included.
