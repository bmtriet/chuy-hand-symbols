# Chuy Hand Symbols

Font ký hiệu viết tay A–Z, dựng lại từ video tham chiếu.

![Bảng chữ mẫu](ChuyHandSymbols-preview.png)

## Tải và cài đặt

[Tải font TTF](ChuyHandSymbols-Regular.ttf?raw=true), mở file và chọn **Install Font / Cài đặt**. Trong ứng dụng, chọn **Chuy Hand Symbols**.

## Ký tự hỗ trợ

- A–Z và a–z; chữ thường dùng cùng ký hiệu với chữ hoa.
- Khoảng trắng.
- Chưa hỗ trợ số, dấu câu hoặc dấu tiếng Việt.

Các nét được dựng lại từ video, không phải bản trích xuất nguyên bản từng pixel.
